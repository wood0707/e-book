# 전자책 작업 폴더

`fieldnote-book-workflow` 스킬(경험서 집필)로 작업하는 원고 보관소.

## 폴더 구조

```
book/
├── 00-book-profile.md        Phase 1 책 프로필 (가제·독자·종결어미 등)
├── references/
│   └── confirmed-toc.md      Phase 2 확정 목차 — 모든 챕터 작업의 기준점
├── sources/                  원재료 (블로그·매거진·강의 메모 등)
├── chapters/
│   ├── chapter-01-draft.md   챕터 초안
│   └── chapter-01-final.md   리라이팅 완성본
└── sample-chapter.md         저자 작성 샘플 챕터 (문체 기준점)
```

## 진행 단계

| Phase | 내용 | 상태 |
|---|---|---|
| 1 | 기획 (책 프로필 7항목) | 진행 중 |
| 2 | 목차 설계 | - |
| 3 | 챕터별 집필 | - |
| 3.5 | 원고 통합 점검 | - |
| 4 | 퇴고 (3 Pass) | - |
| 5 | 최종편집 (서문·에필로그·부록) | - |

## 집필 원칙

**"보여주되 가르치지 않는다"**

각 챕터는 장면(30%) → 맥락(40%) → 원칙(30%) 구조를 따른다.
